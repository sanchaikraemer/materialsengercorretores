Conectar ao GitHub

Para o painel conseguir salvar as alterações no site, ele precisa de uma chave de acesso (token) do GitHub. Isso é feito uma única vez neste aparelho.

  1. Entre no GitHub com a conta sanchaikraemer.
  2. Abra github.com/settings/personal-access-tokens/new.
  3. Em Token name, escreva Painel Senger. Em Expiration, escolha 1 ano.
  4. Em Repository access, marque Only select repositories e escolha materialsengercorretores.
  5. Em Permissions → Repository permissions → Contents, escolha Read and write.
  6. Clique em Generate token, copie o código (começa com github_pat_) e cole abaixo.

A chave fica guardada apenas neste aparelho (navegador). Se trocar de celular ou computador, basta gerar outra.
