Conectar ao GitHub

O painel precisa de uma chave de acesso do GitHub para salvar as alterações no site.

Se você já tem a chave em outro aparelho, não precisa criar outra. No aparelho que ainda entra no painel, toque em Chave lá em cima, depois em Copiar, mande o código para você mesmo (WhatsApp, e-mail) e cole aqui embaixo. A mesma chave funciona no celular e no computador ao mesmo tempo.
Não tenho a chave em aparelho nenhum — criar uma nova no GitHub
  1. Entre no GitHub com a conta sanchaikraemer.
  2. Abra esta página do GitHub. Se aparecer uma tela de erro com um unicórnio rosa, é o GitHub que demorou demais: atualize a página que ela abre.
  3. Em Token name, escreva um nome que ainda não exista — por exemplo Painel Senger. Se o GitHub disser que o nome já está em uso, mude o nome; não use Regenerate na chave antiga, porque isso desliga o outro aparelho.
  4. Em Expiration, escolha No expiration (sem vencimento). É o que evita ter de repetir isso daqui a alguns meses.
  5. Em Repository access, marque Only select repositories e escolha materialsengercorretores.
  6. Confira em Permissions → Repository permissions → Contents se está Read and write.
  7. Clique em Generate token, copie o código (começa com github_pat_) e cole abaixo.
