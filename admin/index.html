Conectar ao GitHub

O painel precisa de uma chave de acesso do GitHub para salvar as alterações no site.

Se você já tem a chave em outro aparelho, não precisa criar outra. No aparelho que ainda entra no painel, abra Publicação → Acesso técnico para publicar, toque em Gerenciar chave, depois em Copiar, mande o código para você mesmo (WhatsApp, e-mail) e cole aqui embaixo. A mesma chave funciona no celular e no computador ao mesmo tempo.
Não tenho a chave em aparelho nenhum — criar uma nova no GitHub
  1. Entre no GitHub com a conta sanchaikraemer.
  2. Abra esta página do GitHub. Se aparecer uma tela de erro com um unicórnio rosa, é o GitHub que demorou demais: atualize a página que ela abre.
  3. Em Token name, escreva um nome que ainda não exista — por exemplo Painel Senger. Se o GitHub disser que o nome já está em uso, mude o nome; não use Regenerate na chave antiga, porque isso desliga o outro aparelho.
  4. Em Expiration, escolha No expiration (sem vencimento). É o que evita ter de repetir isso daqui a alguns meses.
  5. Em Repository access, marque Only select repositories e escolha materialsengercorretores.
  6. Confira em Permissions → Repository permissions → Contents se está Read and write.
  7. Clique em Generate token, copie o código (começa com github_pat_) e cole abaixo.

    Preços e margem

    Informe o custo de cada item e a venda desejada. A margem sai sozinha. Custo e margem ficam só aqui, na sua conta — quem vira preço no site é a venda desejada, e só depois de você clicar em “Publicar no site”.

    Clique em “Publicar no site”: ele mostra a lista antes de gravar e já guarda o custo e a margem junto. O “Salvar custos e margens” serve para guardar só o que é interno, sem mexer no site.
    Dados salvos neste aparelho ✓

    Nenhum custo aparece aqui neste aparelho. Os custos são guardados na sua conta do GitHub, em repositório privado, e descem sozinhos quando o painel abre. Se a mensagem acima disser que não deu para alcançar a conta, use Importar backup com o arquivo que você exportou.

    Como as contas são feitas

    Margem = o preço menos o custo. Enquanto a venda desejada estiver vazia, a margem mostrada é a do preço que está no site; assim que você informa a venda desejada, ela passa a mostrar a margem dessa venda. Tocando no ⌄ ao lado do nome do item aparecem: Custo - 5% = custo × 0,95 e Custo - 10% = custo × 0,90, para quando o cliente pede abatimento. Custo e margem são informação interna e não vão para o site.
