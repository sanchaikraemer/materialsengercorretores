ATUALIZAÇÃO — MATERIAL SENGER CORRETORES — v171

Este ZIP contém o projeto completo atualizado.

NOVIDADES DESTA VERSÃO
- retirado o “Abrir” genérico dos cartões da Visão geral; os cartões agora são somente resumo;
- em Pendências do cadastro, não existe mais “Abrir o empreendimento” genérico; quando a pendência tem editor no painel, aparece um atalho direto para o módulo correto (Capa e logo, Galeria, Plantas ou Folder e vídeo);
- pendências que ainda não possuem editor específico ficam apenas como conferência, sem botão inútil;
- o módulo Configurações foi retirado do menu;
- a Chave do GitHub foi movida para Publicação > Acesso técnico para publicar e fica recolhida no uso normal;
- o botão de “Sair do painel”/encerrar sessão foi retirado da navegação;
- Correção pelo INCC agora também mostra todos os itens à venda separados por empreendimento, em acordeões (disponíveis e alugados; vendidos ficam fora);
- a tabela interna possui: Unidade, Custo, Custo - 5%, Custo - 10%, Preço de venda atual e Margem extra;
- Margem extra = Preço de venda atual - Custo;
- os custos são internos e ficam apenas no navegador deste aparelho (localStorage). Eles NÃO são enviados ao data.js, GitHub ou site público;
- a tela possui Importar custos e Exportar backup para levar a tabela interna entre computadores sem expor esses valores;
- enquanto as tabelas de custo não forem fornecidas, os campos de custo ficam vazios e podem ser preenchidos pelo painel;
- cache atualizado para v171.

PADRÃO DE ARQUIVOS MOSTRADO NO PAINEL
- Capa principal: WEBP, JPG ou PNG — 1600 × 900 px — até 5 MB.
- Fotos da galeria: WEBP, JPG ou PNG — 1600 × 900 px — até 5 MB cada.
- Plantas: WEBP, JPG ou PNG — 2000 × 2000 px — fundo claro — até 6 MB.
- Logo do empreendimento: PNG ou WEBP — 1600 × 600 px — fundo transparente — até 3 MB.
- Folder: PDF — até 25 MB.
- Vídeo: MP4, WebM ou Ogg — recomendado 1920 × 1080 px (Full HD) — até 80 MB; para arquivos maiores, usar YouTube/Vimeo.

COMO FUNCIONA O ARMAZENAMENTO DE MATERIAIS
Quando um arquivo novo é anexado pelo painel e publicado, ele é enviado ao próprio repositório GitHub. Os novos caminhos seguem a organização assets/<empreendimento>/...

IMPORTANTE SOBRE CUSTOS
Os custos não ficam no repositório público. Eles são gravados somente no navegador que está usando o painel. Isso evita expor custo e margem comercial no site. Se trocar de computador/navegador, esses valores não acompanham automaticamente.

COMO PUBLICAR NO GITHUB
1. Substitua os arquivos alterados pelos desta versão, mantendo as pastas.
2. Confirme o commit na branch usada para publicação.
3. Aguarde a atualização do site.
4. Confirme no painel que a versão carregada é v171.
